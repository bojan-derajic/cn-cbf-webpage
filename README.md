# CN-CBF — project page

Project page for the IROS 2026 paper *CN-CBF: Composite Neural Control Barrier
Function for Robot Navigation in Dynamic Environments*.

Plain static HTML, served with GitHub Pages from the `main` branch, root folder
(Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`).

## Files

- `index.html` — the whole page
- `style.css` — styling
- `assets/` — logos
